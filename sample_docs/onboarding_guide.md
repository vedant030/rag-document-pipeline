# Onboarding Guide

New team members receive an invitation email on their first day. Accept the invitation, set up multi-factor authentication, and sign in. Workspaces that use single sign-on skip the password step and sign in through the company identity provider.

API keys are created in the developer settings page. Each key is shown only once, so store it in a secrets manager immediately. Keys can be restricted to read-only access and rotated at any time without downtime.

Every new engineer is paired with an onboarding buddy for the first two weeks. The buddy walks through the architecture, the deployment pipeline and the on-call schedule, and reviews the engineer's first pull requests.

Request access to production dashboards through the access portal. Access is granted for 90 days and renewed automatically if the engineer is still on an on-call rotation.
